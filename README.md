# Brick Shelf Studio

Build Lego-style furniture from flat 3D-printed panels that slide and snap together on a 40 mm grid: cubes with walls, open sides, hinged doors (left, right, top, bottom; filament pin; magnet or snap latch), sliding panels, and drawers (1 or 2, dividers, pull, label slot, stop lip). Short Lego-proportion studs align stacks; dovetails, M4 bolt holes, gussets and ribs carry load (see STRENGTH.md). Export is a 3MF with every part laid flat for a Bambu A1 (256 mm). Deep links: `?preset=drawers&open=1&explode=1`.

Shares its 3D, manifold and 3MF code with Gridfinity Studio.
