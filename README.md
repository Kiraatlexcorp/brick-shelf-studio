# Brick Shelf Studio

Build Lego-style furniture from flat 3D-printed panels that snap together. MVP: one cube from 6 panels on a 40 mm grid, edge tabs into deck slots, big studs on top and sockets underneath so cubes stack, a fit-test print, and a 3MF with each panel laid flat for a Bambu A1.

Shares its 3D, manifold and 3MF code with Gridfinity Studio.
